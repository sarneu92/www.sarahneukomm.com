# Sarah Neukomm

Statische One-Page-Webseite mit DE/EN-Sprachwechsel. Keine Installation nötig.
Alle Dateien in diesem Ordner gemeinsam hochladen; `index.html` muss im
Veröffentlichungsordner direkt erreichbar sein. Relative Pfade unterstützen
GitHub Pages auch unter einem Repository-Unterpfad.

## Medien

- `ocean-light.mp4`: Originalvideo aus dem gelieferten Prototyp.
- `poster.jpg`: zugehöriges Standbild aus dem Prototyp.
- `sarah-neukomm.jpg`: nachgereichtes Foto mit den gemusterten Kacheln;
  unveränderter Bildausschnitt, für die Webseite als JPEG gespeichert.

Bei weniger Bewegung startet das Video nicht. Bei Ladeproblemen oder ohne
JavaScript bleibt das Standbild sichtbar. Eine Taste erlaubt Anhalten und
erneutes Starten; bei blockiertem Autoplay kann die Wiedergabe manuell starten.
Die Sprachwahl wird, sofern möglich, lokal im Browser gespeichert.

## Veröffentlichung

GitHub: Settings > Pages > Deploy from a branch > main > / (root) > Save.
Keine externen Schriftarten, Trackingdienste oder Bibliotheken eingebunden.
Der Kontaktlink öffnet das E-Mail-Programm; es gibt kein Formular-Backend.

## Prüfung

Offline geprüft: Dateiverweise, HTML, JS-Syntax, MP4-Container/Codec und
simulierte Funktionsprüfungen der Sprach- und Videosteuerung.
Echte Browser-Wiedergabe und visuelle Responsive-Prüfung in der Arbeitsumgebung
wegen Zugriffsbeschränkungen nicht verifiziert. Vor Veröffentlichung im eigenen
Browser und auf einem Smartphone prüfen.
